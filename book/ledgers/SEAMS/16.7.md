## Open questions / for the editor
1. ε_r = 3.9 for a-SiO₂ is used as the conventional static value without a fetched source (WE 16.7, Limit Checks 16.7b,d). An open
   source should be added at review, or the value labelled assumed in the text (it is labelled "the static permittivity").
2. γ_l = 1 eV for silica is an assumed value (no open source fetched for the Berret–Meissner γ's). It enters only K_ph (relaxation
   corrections, crossover ∝ K^{-1/4}) and the core/host split of the scattering estimate; the host term and the dark-photon rate are
   γ-independent. Captions and text say "assumed".
3. Scattering estimate: the campaign value 3.7e-2 (SPINE) used C = 3e-4, P̄ = 1.4e20 and a halo with ⟨v⟩ = 358 km/s; with the public
   C = 2.6e-4 (Buchenau Table I) and the book halo (354.1 km/s) the same model gives 3.1e-2. Both are inside the stated factor 3.
4. Novelty: no "new"/"derived here" wording (Ch13 R6). NOVELTY N9 says κ²tanδ/ε_r is prior art as a formula; text presents it as
   the loss function read at the dark-photon mass.
5. 16.9 table row (Glasses) says scattering through the deformation potential is not fixed by tanδ₀; true, but eq:16.7-host shows
   the host term is fixed by the acoustic C_l. 16.9 may add that clause.
6. Taraskin's B is printed with unit cm⁻¹; the book uses it with C in cm⁻² and ω̃ in cm⁻¹ (dimensionally B in cm⁰). Crossover
   (A/B)^{1/2} = 115 cm⁻¹ assumes that reading.
7. Map caption (ch16.tex) could add \cref{lim:16.7a,lim:16.7b,lim:16.7c,lim:16.7d}; map16.py rerun pending (16.1 note).

## Open questions / for the editor
1. SPINE wording "resonant-only (Tamm–Dancoff)" conflates two things. The text separates: resonant-only real part (×2 error),
   retarded TDA (both poles, as eq:4.9-epsmac), coupled form. Key results are stated for the resonant-only form, as E.15 does.
   The publication's evaluation (retarded or resonant-only) is not stated in its text; the book does not attribute either.
2. E.15 quotes a_x ≈ 4.9 nm; 4.9 has 4.2 nm (μ_x = 0.148). 10.5 uses 4.2 nm. E.15 should be updated (as E.6, 4.9 SEAM item 2).
3. E.15 quotes E₀ = 4.8 eV and ε₁ ≈ 5.5 at 0.7 Å⁻¹ (unsourced in the book). 10.5 uses the tables (ε₁ = 4.45 at 1.3 eV, ratio 2.12),
   a one-oscillator E₀ = 9.1 eV fixed by the f-sum and the static value (2.23), and Cappellini static 4.50 (2.25). All ≈ 2.
   E.15's numbers could be aligned.
4. The 10 % coupling error is an estimate (one-oscillator model + size of local fields). The model gives 2.6 % for the RPA + LF coupling block at 0.91 keV, consistent with ≲ 10 %; the BSE coupling block itself was not computed.
5. Fig. 10.4 is at 0.91 keV along [100] (grid-commensurate), not 1 keV; model EPM (gap 0.82 eV), coarse 10³ grid validated for
   the IP spectrum against 15³ (5–8 % below 6 eV); the bound lines are not resolved (stated). Fitted bands double count part of
   the excitonic shift (as 4.9).
6. Selection-rule argument uses point-group language without irreps beyond naming Γ₂₅′; C.17 has no Δ/Γ labels. 13.9 owns the
   nonsymmorphic classes.
7. 2507.14345 is cited as Phys. Rev. Research 8, 013056 (2026) per Crossref; its "about an order of magnitude" refers to the NaI
   reach above 2 MeV with their background model.

8. Compute policy: fig10_4_data.py runs ≈ 43 min, above the ~10 min guideline for Python model scripts (the dense K^d build
   dominates). It is a model script (no first-principles code); NK = 10 is the smallest grid that passed the IP gate. If the editor
   prefers, move it to DEFERRED-COMPUTE; the npz is saved, so fig10_4.py re-plots in seconds.
9. Learning outcome (iv) 'static, resonant-only': the static rung gets one paragraph (pointer to 4.9's criterion); no number.

## The reader now knows
- Grand-canonical setting: H_μ = H − μ_ch N̂_e, energies measured from μ_ch; retarded 𝖦^R(k,t) = −iΘ⟨{c_k(t), c_k†}⟩ (eq:4.7-GR) as
  survival amplitude of an added electron or hole; free 𝖦^R_0 = 1/(ω − ξ_k + i0⁺), ξ_k = E_k − μ_ch (eq:4.7-G0), T-independent.
- Keyresult Lehmann (eq:4.7-lehmann) and spectral function 𝖠 = −Im𝖦^R/π (eq:4.7-A): addition and removal poles; 𝖠 ≥ 0, ∫𝖠 = 1;
  removal part = 𝖠 n_F (detailed balance), occupation ⟨c†c⟩ = ∫𝖠 n_F (eq:4.7-occ). Normalization stated: B&F/Mahan write −2 Im 𝖦.
  Photoemission ~ 𝖠 n_F, inverse photoemission the addition part (qualitative). 𝖦^A = (𝖦^R)*.
- Time-ordered T = 0 function (eq:4.7-GT, eq:4.7-GTlehmann): removal poles above the axis; = 𝖦^R for ω > 0, 𝖦^A for ω < 0; why it is
  the object of T = 0 perturbation theory (Dyson series time-ordered). Notation rule: bare 𝖦 with real argument = time-ordered,
  imaginary = Matsubara, complex z = ∫𝖠/(z − ω').
- Dyson equation derived from the equation of motion (keyresult eq:4.7-dyson): Σ^R ≡ 𝖥^R/𝖦^R, legitimate since 𝖦^R has no zeros in the
  UHP; matrix form in a crystal (eq:C.7-dyson); iteration picture, proper part and diagrams deferred to 4.8; link to 2.4's i0⁺ → iΓ_w/2.
  Im Σ^R = −π𝖠|𝖦^R|² ≤ 0 (eq:4.7-ImSigma); Σ^R → ⟨{[c, H_int], c†}⟩ (static mean field, HF of 3.4 with exact occupations) at large ω;
  Σ − Σ(∞) obeys KK.
- Quasiparticle keyresult (eq:4.7-qp): E_qp, z_qp = [1 − ∂ReΣ]⁻¹, Γ_qp = −2z_qp ImΣ (same relation as E-13); time form, resonance pole,
  lifetime 1/Γ_qp; weight z_qp + incoherent 1 − z_qp; validity (Σ slow over Γ_qp; Γ_qp ≪ |E_qp|). Phase-space estimate Γ ∝ ξ_k² near
  E_F (triangle ξ_k²/2), Luttinger's theorem, Landau picture; semiconductor: CBM electron has zero width, e–e width zero below ~E_g above
  the edge, phonon part → 6.3.
- Computational connection: linearized quasiparticle equation E_qp ≈ ε_nk + z_qp Re⟨Σ(ε_nk) − v_xc⟩ (eq:4.7-G0W0); Si PBE 0.602 eV vs
  1.17 eV (E.1 numbers, same citation); GW → 4.8; App. E.3.
- WE 4.5 in this build (planned WE 4.12; we:4-level): Anderson model without U, EOM closes, Σ_d = Σ|V|²/(ω − E_k + i0) (eq:4.7-Sigmad) =
  R(z) of eq:D.3-resolvent; WE 2.1 flat band (E_w = 1 eV, Γ = 10 meV): Σ(E_d) = −iΓ/2, slope 0.0064, z_qp = 1.0064, Γ_qp = z_qpΓ = D.3's
  Γ/(1 − R′); peak 2/(πΓ) = 63.7 eV⁻¹; exact within 1.3% to 10Γ; z_qp > 1 compensates Lorentzian weight 0.0064 beyond band edges;
  𝖦^R_dd(t) = −i c_i(t)e^{−iE_d t} (WW of 2.4); T only in occupation: 0.787 vs n_F = 0.818 at T = 20 meV, E_d = −30 meV. Fig. fig:4-level.
- Imaginary time: O(τ) = e^{τH_μ}Oe^{−τH_μ}; Matsubara 𝖦(k,τ) = −⟨T_τ c(τ)c†⟩ (eq:4.7-Gtau); antiperiodic (D.10); ω^F_j, ω^B_j series
  (eq:4.7-Gmats); Matsubara Lehmann with weights (p_i + p_f); keyresult 𝖦(iω^F_j) = ∫𝖠/(iω^F_j − ω'), continuation iω^F_j → ω + i0⁺
  (eq:4.7-continuation), uniqueness via C.5/Baym–Mermin; Dyson at iω^F_j; why imaginary time (one Dyson series, Wick → 4.8).
- Occupation as Matsubara sum with convergence factor (eq:4.7-occmats) and the contour picture (Fig. fig:4-matsubara).
- Density response in imaginary time: R_ab(q,τ) (eq:4.7-Rtau), Lehmann at iω^B_j with (p_i − p_f) and the j = 0 β term (eq:4.7-Rmats);
  keyresult R_ab(ω) = R_ab(iω^B_j → ω + i0⁺), j > 0 (eq:4.7-Rcont); β term = isothermal static response of 4.1 (Kubo).
- Bubble: R⁰(iω^B) = (1/V)Σ_k TΣ 𝖦₀𝖦₀ = (1/V)Σ(n_F(ξ_k) − n_F(ξ_{k+q}))/(iω^B + ξ_k − ξ_{k+q}) (eq:4.7-bubble), proved in D.10 directly
  and by frequency sum; continued = independent-electron response, Im part = transition sums of eq:2.5-indep.

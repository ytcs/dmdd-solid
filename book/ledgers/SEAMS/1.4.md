## The reader now knows
- Non-relativistic mediator couplings (eq:1.4-Lint): vector −A'_μ(y_χJ^μ_χ + y_eJ^μ_e + y_NJ^μ_N), scalar −φ_V(y_χ𝓃_χ + y_e𝓃_e + y_N𝓃_N)
  (KKL 2101.08275 Eq. (7)).
- Yukawa potential V(x) = y_χy_e e^{−m_V|x|}/(4π|x|) (eq:1.4-yukawa), from the static Klein–Gordon/Proca equation and the Green's
  function e^{−mr}/4πr (App. C.9, derived with a contour integral); vector repels like-sign couplings, scalar attracts (eq:C.9-U).
- Ṽ(q) = y_χy_e/(q² + m_V²) (eq:1.4-Vq, keyresult); sign reversed for scalars; only |Ṽ|² enters rates.
- Static limit valid because ω ≤ qv_max: correction ω²/q² < 7 × 10⁻⁶ (C.9).
- Definitions σ̄_e = μ_χe²|Ṽ(q₀)|²/π, F_DM = Ṽ(q)/Ṽ(q₀) (eq:1.4-defs); |Ṽ|² = πσ̄_eF_DM²/μ_χe² (eq:1.4-Vsq); Yukawa values
  (eq:1.4-yukawa-sigma) = KKL Eqs. (11), (12). σ̄_e is a vacuum quantity; screening belongs to the target response (4.4).
- Light-mediator σ̄_e is the cross-section of no process (Rutherford divergence, cut off by threshold q and screening).
- Limit box "Heavy and light mediators" (EMV 1108.5383 Eq. (15)): validity q ≤ 2m_χv_max (heavy), q ≳ E_g/v_max ≈ 0.1q₀ (light);
  leading corrections stated.
- Dark photon: mixing +(ζ/2)FF′ removed by A = Ã + ζA′ (C.9, eq:C.9-mix, eq:C.9-mixed); dark photon couples to J^μ_em with
  strength ζe; y_e = −ζe, protons +ζe, neutrons 0 (keyresult). σ̄_e = 4αζ²y_χ²μ_χe²/(m_V² + α²m_e²)² (eq:1.4-darkphoton).
- Worked example 1.6 (we:1-darkphoton): Lin's thermal benchmark (10 MeV, 30 MeV, y_χ = 0.3, ζ = 10⁻⁴) → σ̄_e = 3.0 × 10⁻³⁹ cm².
  Freeze-in benchmark (1 MeV, 10⁻¹² eV, 3 × 10⁻⁶, 10⁻⁶) → light limit, σ̄_e = 6.1 × 10⁻³⁸ cm². Freeze-out ↔ heavy, freeze-in ↔ light.
- In-medium mixing (one paragraph): ζ_eff² = ζ²m_V⁴/{[m_V² − Re Π]² + [Im Π]²} (HLZ 1608.01994 Eqs. (5), (6)); for scattering,
  1/|ε|² inside the target response (KKL Eqs. (6), (8)). Computational pointer to App. E.6.
- σ_p = μ_χp²y_χ²y_N²/(πm_V⁴) (Lin Eq. (99)); coherence σ_N = σ_p(μ_χN/μ_χp)²A² (eq:1.4-sigmaN); isospin-violating A → Z + (A−Z)y_n/y_p;
  dark photon A² → Z². Silicon: σ_N = 950σ_p at 100 MeV, 3100σ_p at 1 GeV.
- Absorption kinematics ω ≈ m_φ, q = 𝐩_φ, |𝐩_φ| ≈ 10⁻³ω (eq:1.4-absorption); reach m_φ ≥ E_g vs m_χ ≥ 2E_g/v_max² ≈ 0.3 MeV.
- Dark-photon absorption rate ℛ = ρ_χζ_eff²σ₁(m_φ)/(ρ_Tm_φ) (eq:1.4-dp-abs; HLZ Eq. (7)).
- ALP: g_aee φψ̄iγ⁵ψ, −¼g_aγγφFF̃ = g_aγγφE·B; NR couplings (eq:1.4-alp, Mitridate Eq. (18)); NLO spin-current term dominates.
- Scalar: g_φee φψ̄ψ; NR couplings (eq:1.4-scalar); LO density term suppressed by charge conservation; NLO kinetic-energy density
  dominates and is not fixed by optical data.
- Table 1.2 (tab:1-interactions); Fig. 1.7 (fig:1-fdm).
- Inelastic DM (Tucker-Smith & Weiner): Δ_χ enters only through ω_q; endo/exothermic.

## The reader now knows
- Vertex lines: DFPT g already screened (eq:6.2-screen); static error (ω_Q/E_g)² ≈ 3e-3; dividing g by ε(Q) double counts; bare ionic
  potential overstates long-range coupling by ~ε∞.
- External lines: ρ^scr_mn(k,q) = Σ_G (ε̃⁻¹)_{G0}(q,ω) ρ_mn(k,q+G) (eq:13.4-rhoscr). Exact factorization (eq:13.4-rhoLF, proof D.36):
  (ε̃⁻¹)_{G0} = (1/ε_mac)[δ_G0 + (f̄R̄)_G0] ⇒ ρ^scr = ρ^LF/ε_mac, ρ^LF = ρ(q) + Σ_{G≠0} v_C(|q+G|) R̄_G0 ρ(q+G) (RPA; a kernel adds its
  elements incl. head). Every other term is linear in ρ^LF ⇒ one external 1/ε_mac(q,ω) multiplies the whole amplitude.
- In the window ε_mac(q,ω) real up to O(g²): ε₁⁰ = Re ε_mac at n_g = 0, ε₂⁰ = 0; external weights retarded = advanced.
- Pair channel: TDH density matrix to second order; source ς_ab = Σ_m[x ϱ^y − ϱ^y x + y ϱ^x − ϱ^x y]; on shell ς_cv = M^±[ρ^scr]
  (band-sum theorem re-derived without Fock space, D.36); second-order KS density δ𝓃^{(2)}_G(q+Q) (eq:13.4-dn2), all band pairs;
  potential ε̃⁻¹ f_Hxc δ𝓃^{(2)} (= W^scr δ𝓃^{(2)} in RPA). Keyresult eq:13.4-Mscr: amplitude N^{-1/2}(n+½±½)^{1/2} M̃^±/ε_mac(q,ω),
  M̃^± = M^±[ρ^LF] + Σ_GG′ ρ_cv(k,q+Q+G) W^scr_GG′(q+Q, ω_f) δ𝓃^{(2)}_G′; W^scr retarded (out-state, as 8.7), final-pair index first;
  additive, no 1/|ε|⁴. ω_f = ω ∓ ω_Qν.
- Pinning: q+Q ≡ k_c (mod G), |k_c| = 1.94 keV, ω_f within tenths of eV of E_g; one W^scr(k_c, ω_f) for every q and for optics (q = 0,
  pair momentum Q); only δ𝓃^{(2)} depends on q.
- Limits (D.36): (1) source ∝ applied potential at q+Q ⇒ M̃ = M[ρ^LF]/ε(q+Q, ω_f) (no LF); (2) rigid translation (Q = 0, g = u[𝒜,h])
  ⇒ convective part screened by ε(q, ω_f); four-path term alone gives 1/ε(q,ω); pair channel supplies 1/ε(q,ω_f) − 1/ε(q,ω).
  Outside the window; a check only.
- Keyresult eq:13.4-Lscr: L^PA = ε₂^PA/(ε₁⁰)² + O(g⁴), ε₂^PA = (8π²α/Ωq²)⟨⟨Σ w_±|M̃^±|²δ⟩⟩ = Im ε_mac at O(g²); optical theorem
  (D.36) with Im W = W†(Im R⁰)W from eq:8.7-factor. From 13.4 on, L^PA is the screened function; 13.3's is its IP value. Reductions:
  no pair, no LF ⇒ L^PA_IP/ε₁,00²; q → 0 ⇒ optical ε₁(ω) and measured PA absorption with the pair channel inside (13.5).
  Fails outside the window (ε₂⁰ ≠ 0; external lines absorptive) → 13.6.
- Bookkeeping: rate without pair channel = 𝒳 RPA+LF (external) / IP (pair), report it so.
- ALDA source (eq:13.4-kxc): k_xc = d³(𝓃ε_xc)/d𝓃³; cross term k_xc δ𝓃_x δ𝓃_y (coefficient 1) at (q+Q+G, ω_f), screened by ε̃⁻¹;
  absent in RPA; consistency with LDA-DFPT g requires it. Exchange: k_x = −(2/3)f_x/𝓃; size vs Hartree pair term
  (2/3)(|k_c|/2k_F)² × O(1) = (2/3)(0.074) = 0.05 [estimate]; Si valence 𝓃 = 0.200 Å⁻³, k_F = 1.81 Å⁻¹, |k_c| = 0.983 Å⁻¹.
- Definitions: 1 + δ_LF = L^PA(LF, no pair)/L^PA(head only); 1 + δ_pair = L^PA(LF + pair)/L^PA(LF only). Head part of δ_LF:
  (ε₁,00/ε_mac)² = 1.25, 1.31 at 0.944, 0.986 keV; wings not in published data; proxy eq:E.16-dLF (~10 core-h).
- Si numbers (KKL 2101.08275 GPAW RPA; we13_4.log): q→0: ε_00 10.2, ε_mac 9.1 (13 %, 22 % below 11.7). |q| = 0.944, 0.986 keV at
  1.20 eV: ε₁,00 6.31–6.93, ε_mac 5.52–6.20, ε₂ = 0; 1/ε₁² 0.021–0.025 (head), 0.026–0.033 (mac); unscreened too large ×40–48 / ×30–38;
  vs 1/ε∞² = 0.0073: ×2.9–3.4 / ×3.6–4.5; static 6.1–6.6 at 1 keV, 3.2–3.7 near 2 keV; window 1.184 → 1.47 eV: factor −4 to −5 %;
  dlnε₁/dlnω 0.07–0.08 ⇒ ω → ω_f shift 1e-3 in ε₁, 2e-3 in L. Pair momentum (1.87–2.03 keV, 1.2 eV): ε₁,00 3.3–3.8, ε_mac 2.9–3.5,
  ε₂ ≈ 1e-3; coherent-potential factor 0.07–0.12. Static vertex 3e-3; ionic < 1e-4 (8.4).

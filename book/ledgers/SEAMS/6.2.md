## The reader now knows
- Bare potential of a displaced ion: component ~ Z e²/Q at small Q for every crystal; electrons screen it.
- Screened vertex: ∂V_KS = (1 − f_Hxc R⁰)⁻¹ ∂V_ext = (1 + f_Hxc R) ∂V_ext (eq:6.2-screen), from eq:5.4-dV and ∂𝓃 = R⁰∂V_KS;
  RPA → ε⁻¹_GG′(Q, 0) of 4.4; with f_xc: test-electron dielectric function (vs test charge of 4.4); static = adiabatic, corrections
  ω_ph/E_g; metals: dynamic (Bardeen–Pines, Giustino Eq. (5)).
- Long wavelength: TF metal Z e²Q/(Q² + k_TF²) → linear in Q; insulator head 1/ε∞ (11.7 Si) does not remove 1/Q, local fields replace
  Z_κ by Z*_κ (Pick–Cohen–Martin): screened ion = dipole eZ*·u in ε∞; Si Z* = 0 → quadrupole first; GaAs Z* = 2.1 → Fröhlich.
- DFPT form g = ℓ_Qν⟨u_{m,k+Q}|Δ_Qν v_KS|u_nk⟩_Ω, Δ_Qν v_KS = Σ(M_cell/M_κ)^{1/2}e^α_κν ∂_{κα,Q}v_KS (eq:6.2-g) = Giustino Eqs. (33)–(38)
  with M0 = M_cell, EPW Eq. (2); ℓ carries mass/frequency, matrix element in eV/Å (mass-weighted displacement); gauge dependence;
  computational connection (one DFPT run per Q; matrix elements cheap; → E.4, E.5).
- Translation invariance: Σ_κ ∂_{κα,0}V_KS = −i[p_α, H_KS] (nonlocal included); Σ_κ⟨mk|∂_{κα,0}V_KS|nk⟩ = −i(ε_n − ε_m)p^α_mn
  (eq:6.2-asr): acoustic sum rule of the vertex, counterpart of eq:5.2-asr; g_nn ∝ Qℓ_Q ∝ Q^{1/2} → 0; interband elements = rigid
  translation of the state (−ℓê·∇ψ), cancel against Allen–Heine in 6.3; codes set Q = 0 acoustic vertices to zero.
- Deformation potential: local strain S_αβ of a long acoustic wave; δε = D^n_αβ S_αβ (relaxed internal coordinates); Bardeen–Shockley
  argument; g_nn = iℓ_Q Q·D^n·ê (eq:6.2-D); isotropic E1 = Ω∂ε/∂Ω (Giustino Eq. (6)), LA only, |g|² = E1²Q/(2M_cell c_LA);
  Si valleys: Herring–Vogt D = Ξ_d 1 + Ξ_u k̂_c k̂_c → LA Ξ_d + Ξ_u cos²θ, TA Ξ_u sinθcosθ (Li Eqs. (13), (14)); DFPT Ξ_d = 1.01 eV,
  Ξ_u = 8.84 eV; Q = 0.01 Å⁻¹ along axis: ω 0.55 meV, ℓ 0.26 Å, |g| = 26 meV; perpendicular 2.6 meV; linear to ~0.1 Å⁻¹.
- Piezoelectric coupling (form): g^pz = −(e/ε∞)ℓ_Q Σ Q̂_α e^pz_αβγ Q̂_β ê_γ ρ_mn (cubic), ∝ Q^{-1/2}, direction-dependent; from
  dynamical quadrupoles in first-principles work; dominates acoustic scattering in GaAs (Brunin).
- Optical deformation potential d^n_ν (eq:6.2-d), g_nn(k, 0) = ℓ_0ν d^n_ν, Hellmann–Feynman meaning (shift per unit mass-weighted
  sublattice displacement; Si: dε/du with atoms ±u); first- vs zero-order deformation potentials; zero for Si conduction intravalley
  (symmetry; Li); Si holes 10.45 eV/Å combined over degenerate bands → ℓ_0 = 0.024 Å, |g| ≈ 0.25 eV; intervalley (zone-boundary)
  scattering of hot electrons (→ E.12).
- Long-range vertex g^L (D.14-gL displayed; Verdi–Giustino Eq. (4)); longitudinal only; 1/Q intraband; interband finite,
  direction-dependent (eq:A.5-optical).
- Keyresult Fröhlich vertex g^L = iC_F ρ_mn/Q, C_F² = (e²ω_L/2Ω)(1/ε∞ − 1/ε0) (eq:6.2-frohlich), C_F in eV²; Verdi–Giustino Eq. (1)
  converted; meaning of 1/ε∞ − 1/ε0 (ionic part of the screening); |g|² ∝ 1/Q² like a light mediator.
- Fröhlich constant: second-order shift of a band-bottom electron −α_F ω_L (derived, integral (π/2)(2m*/ω_L)^{1/2});
  α_F = ΩC_F²(2m*ω_L)^{1/2}/(4πω_L²) = α(1/ε∞ − 1/ε0)(m*/2ω_L)^{1/2} (eq:6.2-alphaF); polaron named; cloud size (2m*ω_L)^{-1/2}.
- WE 6.2 (we:6-frohlich): 1/ε∞ − 1/ε0 = 0.01439; C_F² = 4.11e3 eV⁴, C_F = 64.1 eV²; |g^L| = 3.25 eV at 0.01 Å⁻¹ (19.7 eV), 0.33 eV
  at 0.1 Å⁻¹; m* = 34.24 keV, √(m*/2ω_L) = 686, α_F = 0.072; shift 2.6 meV; length 39.6 Å (7 a); Q ~ 0.025 Å⁻¹, |g| = 1.29 eV;
  LST route 0.01328 (−8 %), α_F = 0.067 (fivefold amplification of the 1.4 % LST residual); PBE ε∞ with measured ε0 reverses sign.
- Fig. 6.2: |g| vs Q log-log: Q^{-1} (GaAs LO), Q^0 (Si holes optical), Q^{1/2} (Si electrons LA, ∥ and ⊥ valley axis).
- Wannier interpolation: coarse vs fine grids; g^W(R_e, R_p) = ⟨w_m′0|∂V_KS/∂u_{R_pκα}|w_n′R_e⟩ and its Bloch-sum relation (eq:6.2-gW,
  derived; = E.5-ginterp with polarization factors); Giustino–Cohen–Louie, Giustino Eqs. (177)–(179), EPW; locality in R_e (Wannier
  overlap) and R_p (screened displaced atom: no monopole, no dipole if Z* = 0, ≥ R⁻³); eq:3.6-exact argument; polar: R⁻² dipole ↔ 1/Q,
  subtract g^L (D.14-gL / E.5-gL), interpolate g^S, add back; split not unique; ρ in g^L as U(k+Q)U†(k) (same gauge); quadrupoles → E.5.

## Open questions / for the editor
1. NOTATION gives C_F the unit "eV (normalization fixed in 6.2)". With g = iC_F ρ/Q, g and Q in eV, C_F is in eV². Row update below.
2. The brief asked for the density operator as 𝓃̂ (\hat{\nd}); 6.1 writes \op{n}(\vect{r}). 6.2 needs no density operator (only the
   first-order density ∂𝓃 of 5.4), so the clash is untouched; the editor should pick one for 6.1/6.3 onward.
3. Z* index order: 6.2 displays g^L in D.14's force-index-first form, e·Z*·Q. eq:E.5-gL writes (Q+G)·Z*·e, the transposed order
   (the same mismatch D-b flagged for E.4). For cubic GaAs Z* is a scalar and the order is moot. E.5 not edited.
4. Li et al.'s hole optical deformation potential (10.45 eV/Å) is a quadrature combination over the degenerate valence bands (their
   Eq. (12) and the text after it), not a single-band d^n; the text and the Fig. 6.2 caption say so. Their Ξ_d, Ξ_u are DFPT (PBE)
   values, not measured ones; the text says "DFPT".
5. Fig. 6.2 shows the limiting forms with literature/measured constants, not vertices computed point by point (the brief excluded new
   QE runs). A later DFPT/EPW run could overlay computed |g| for Si LA and GaAs LO.
6. The statement that the interband acoustic Q → 0 vertex cancels against the Allen–Heine term is made as a promise to 6.3, with
   Giustino's remark (below Eq. (38)) that codes set those vertices to zero; 6.3 should show the cancellation.
7. The piezoelectric form is derived here by the D.14 steps (one-line chain in the text) for an isotropic ε∞; no external equation
   number is cited for it.

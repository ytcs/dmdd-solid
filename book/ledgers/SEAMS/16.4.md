## The reader now knows
- Frenkel exciton = excitation localized on one molecule; the Frenkel (vacancy–interstitial) pair of 7.4 is unrelated (one sentence).
- Anthracene facts (Rangel et al. 1604.00041 Tables I–III): S1 3.5 eV gas → 3.1 eV crystal; fundamental gap 6.9 eV (IP 7.4 − EA 0.5) gas →
  3.9–4.2 eV crystal; G0W0-BSE crystal S1 3.3 eV; T1 crystal 1.9 eV. Threshold mass 2×3.1 eV/v_max² = 0.883 MeV. t-stilbene bulk
  fluorescence efficiency ≥ 0.63 (2103.08601 Sect. IV B).
- Molecular-basis BSE: eq:4.9-bse in localized orbitals; zero intermolecular overlap ⇒ K^d intramolecular (+ CT pair attraction), K^x between
  molecules couples transition densities only, CT pairs decouple. Molecular form factor eq:16.4-ff (singlet √g_deg inside; rotation
  rule; small-q i q·d). Frenkel Hamiltonian eq:16.4-HF with 𝔍 (real-space lattice sum, self term excluded, macroscopic Fourier component at Q
  removed into ε_mac; Ewald in practice). Davydov splitting named.
- Computational connection → App. E.6 (molecular GW-BSE, Gaussian basis, 0.1–0.3 eV) and E.21 (runs; zero-overlap vs periodic).
- Structure factor eq:16.4-S (transcription of eq:4.9-S); binned sum eq:16.4-binned (completeness of A within a closed manifold) =
  Davydov oscillator-strength sum rule at every q; dipole strength exact, oscillator strengths to O(𝔍/E).
- Three conditions and how they fail: (1) inter-manifold mixing, intensity borrowing eq:16.4-borrow, FIRST order in 𝔍/ΔE; (2) ε_mac and
  η constant across the window (window set by kinematics, η changes on Δω ≈ q v0 = 1.6 eV at 2 keV); (3) bare vertex needs q a_mol ≫ 1;
  static ε_mac − 1 = (2e²/Ωq²)Σ|f|²/E.

## Open questions / for the editor
1. **Return vs book on the mixing order.** The return (WP7-B1-v2 (E5.2′)) states the binned sum is exact up to O((𝔍/ΔE)²) from
   inter-manifold mixing. That is wrong in general: the weight of a window state changes at FIRST order (intensity borrowing,
   2Re[F*𝔍F′]/ΔE), because the cross term of a small amplitude with a large one is first order. The book states first order
   (eq:16.4-borrow); the model confirms it (6 % persisting at all q, where (𝔍/ΔE)² ≈ 1 %). The SOTA/CORRECTIONS entries only qualify
   "exactly"; consider adding this correction to state/CORRECTIONS.md (not edited: brief restricts edits to book/).
2. **Model status.** Every anthracene number beyond the measured S1/T1/gap/structure is a π-electron PPP model (labelled in text and
   captions). Its B_b band is strongly coupled (B_b-only exciton band 3.61–5.58 eV in the model; σ screening omitted), which drives the
   Limit Check deviations; the text calls them "probably overstated". A reviewer may prefer a screened 𝔍 (𝔍/ε_σ) variant; not done.
3. **No measured Davydov splitting quoted.** The classic anthracene 0–0 Davydov splitting (≈ 220 cm⁻¹ in the literature) has no open
   source I could read (Wolf, Craig–Hobbins, Chem. Phys. Lett. 1977 are closed); the WE gives the model's 31 meV (lower component ∥ b)
   without a measured comparison. Add one at the citation audit if a readable source is found.
4. **Limit Check design.** The planned box ("Frenkel-exciton rate binned in ω") is drawn as the rate ratio full/binned against m_χ (the
   kinematic window and q a_mol both move with m_χ; heavy vs light separates them). An earlier version against q at fixed window failed
   because the strongly coupled B_b band overlaps the L_a window in this model.
5. **E.6 promise.** E.6 says 16.4 "reports" the reaction-field vs periodic difference as an uncertainty. 16.4 reports the gas→crystal
   shifts (0.4 eV S1, ≈ 2.9 eV gap) and the periodic G0W0-BSE vs measured S1 (3.3 vs 3.1 eV); the reaction-field-vs-periodic difference
   itself has no published anthracene number in the sources read, and is left to E.21.
6. **Unsized F-row parts.** The 16.4a F row sizes the main correction; CT admixture and the periodic-BSE difference are "unsized" and
   should go to "## Unsized leading corrections (App. F)" in state/DEFERRED-COMPUTE.md (outside book/, not edited).
7. **Map.** ch16.tex map caption now \cref's lim:16.4a; map16.py already tags 16.4 with "Limit Check 16.7", which matches the printed
   number (16.1a = 1, 16.2a–c = 2–4, 16.3a–b = 5–6, 16.4a = 7). Rerun map16.py only if numbering changes.
8. **Mataga–Nishimoto / U = 11.13 eV** are named as modelling choices of the standard PPP method without a citation (the original papers
   were not read). If the editor wants attribution, cite them "as quoted by" a readable source.

## ER-29 (VALUE) Local-field template of the electronic uncertainty budget: +0.067 against +0.066

### Correct statement
The large-q local-field template at 3 MeV with a heavy mediator is δ = +0.066, which gives ln(1 + δ) = +0.064. The value +0.067 in the text of Sect. 10.10 is wrong. Only one setting exists: the script computes this number once, at DSHIFT = 0, from the tables' gap of 1.17 eV. So this is not a case of two settings. The other numbers in the same sentence (+0.009 light, +0.24 at 10 MeV, 7.5 %, 29 %) are correct.

### Evidence
I ran book/figscripts/ch10/nuis10_10.py on a copy in the scratch directory, in about 7 s. The only change was to the print format of the large-q block: I added the unrounded δ. Once the added digits are stripped, the output matches the committed figscripts/ch10/nuis10_10.log line for line (diff empty).

```

   large-q LF     delta = +0.066  ln(1+delta) = +0.064

δ = 0.06646 rounds to 0.066, not 0.067. The definition in the script (lines 121–135) is δ = (R_RPA(q > 2q₀) − R_LF(q > 2q₀)) / R_LF,total. Git history has only the single initial commit (7696d03) for both values, so it gives no second setting.

## ER-30 (VALUE) Norm-conserving f-sum with 100 bands: 0.88 against 0.89

### Correct statement
Both values are right, at different momenta. The ratio of the band sum to q²/2m_e for silicon (SG15 norm-conserving, k = Γ) with 100 bands is 0.88 at |q| = 0.1 Å⁻¹ and 0.89 at |q| = 0.5 Å⁻¹. With 16 bands it is 0.81 at 0.1 Å⁻¹ and 0.78 at 0.5 Å⁻¹. App. E.2 (ch24/E-2) quotes the 0.1 Å⁻¹ values, 0.81 and 0.88, and says "nearly the same at 0.5". That is correct as it stands. App. E.14 (ch30/E-14:86) and Sect. 13.9 (ch13/s13-9:169, :179) write "0.81 with 16 bands and 0.89 with 100 at |q| = 0.1 to 0.5 Å⁻¹". That mixes the 16-band value at 0.1 Å⁻¹ with the 100-band value at 0.5 Å⁻¹. The correction states which momentum each value belongs to. ch30/E-14:96 says "at the upper end of the range in which the norm-conserving sum at Γ reaches 0.89", at 0.507 Å⁻¹. It is correct as it stands.

### Evidence
The primary output is code/COMP-PAER/out/fsum100.txt, from the COMP-PAER Quantum ESPRESSO run (SG15, Γ; the 16-band version of the same sum is in code/COMP-PAER/scripts/formfactor.py):

```

q=0.10 A^-1 N_m=50 ratio=0.855

q=0.50 A^-1 N_m=30 ratio=0.847
q=0.50 A^-1 N_m=50 ratio=0.860

I did not rerun it. No script in code/ writes fsum100.txt, and the run needs the QE HDF5 wavefunctions and pw.x, which are not on the path here. The file is the only primary record.

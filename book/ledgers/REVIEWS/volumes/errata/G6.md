## ER-29 (VALUE) Local-field template of the electronic uncertainty budget: +0.067 against +0.066

### Correct statement
The large-q local-field template at 3 MeV with a heavy mediator is δ = +0.066, which gives ln(1 + δ) = +0.064. The value +0.067 in the text of Sect. 10.10 is wrong. Only one setting exists: the script computes this number once, at DSHIFT = 0, from the tables' gap of 1.17 eV. So this is not a case of two settings. The other numbers in the same sentence (+0.009 light, +0.24 at 10 MeV, 7.5 %, 29 %) are correct.

### Evidence
I ran book/figscripts/ch10/nuis10_10.py on a copy in the scratch directory, in about 7 s. The only change was to the print format of the large-q block: I added the unrounded δ. Once the added digits are stripped, the output matches the committed figscripts/ch10/nuis10_10.log line for line (diff empty).

```

     3 MeV heavy: share of rate from q > 2 q0 0.075 ; removing LF there changes the rate by +0.066 (0.06646)
     3 MeV light: share of rate from q > 2 q0 0.011 ; removing LF there changes the rate by +0.009 (0.00916)
    10 MeV heavy: share of rate from q > 2 q0 0.289 ; removing LF there changes the rate by +0.242 (0.24224)
    10 MeV light: share of rate from q > 2 q0 0.062 ; removing LF there changes the rate by +0.044 (0.04384)

Nuisance band at 3 MeV (power form, quadrature of ln(1 + delta)):
   large-q LF     delta = +0.066  ln(1+delta) = +0.064
  heavy: central 1.85e+04 per kg-yr; 1 sigma factor exp(0.393) = 1.48 ; band 1.25e+04 - 2.75e+04
```

δ = 0.06646 rounds to 0.066, not 0.067. The definition in the script (lines 121–135) is δ = (R_RPA(q > 2q₀) − R_LF(q > 2q₀)) / R_LF,total. This is the template that s10-10:9 describes, "the change of the rate if the suppression above 2q₀ were absent". Git history has only the single initial commit (7696d03) for both values, so it gives no second setting.

### Grep
`grep -rn "0\.06[67]" tex/` shows three hits on this quantity, all in tex/ch10/s10-10.tex: :9 (+0.067), :26 (tab:10-nuisances, +0.066) and :63 (we:10-band3, +0.066). Every other hit of 0.066 or 0.067 in the book is a different quantity: GaAs mass 0.067 m_e, δ^M of ³⁰Si, 0.066 Å, 0.066 fs, 0.066 eV. SPINE.md has no copy of the value.

### Proposed change
tex/ch10/s10-10.tex:9:
- old: `It is $+0.067$ at \SI{3}{MeV} for a heavy mediator,`
- new: `It is $+0.066$ at \SI{3}{MeV} for a heavy mediator,`

### Downstream
Nothing moves. we:10-band3 already uses +0.066 and ln(1 + 0.06646) = 0.0643, which rounds to +0.064. The quadrature (0.247² + 0.289² + 0.078² + 0.0643²)^½ = 0.3934 → 0.393. The factor 1.48, the band 1.25e4–2.75e4 and the 93 % variance share are all unchanged. The script prints all of these, and they match the text.

## ER-30 (VALUE) Norm-conserving f-sum with 100 bands: 0.88 against 0.89

### Correct statement
Both values are right, at different momenta. The ratio of the band sum to q²/2m_e for silicon (SG15 norm-conserving, k = Γ) with 100 bands is 0.88 at |q| = 0.1 Å⁻¹ and 0.89 at |q| = 0.5 Å⁻¹. With 16 bands it is 0.81 at 0.1 Å⁻¹ and 0.78 at 0.5 Å⁻¹. App. E.2 (ch24/E-2) quotes the 0.1 Å⁻¹ values, 0.81 and 0.88, and says "nearly the same at 0.5". That is correct as it stands. App. E.14 (ch30/E-14:86) and Sect. 13.9 (ch13/s13-9:169, :179) write "0.81 with 16 bands and 0.89 with 100 at |q| = 0.1 to 0.5 Å⁻¹". That mixes the 16-band value at 0.1 Å⁻¹ with the 100-band value at 0.5 Å⁻¹. The correction states which momentum each value belongs to. ch30/E-14:96 says "at the upper end of the range in which the norm-conserving sum at Γ reaches 0.89", at 0.507 Å⁻¹. It is correct as it stands.

### Evidence
The primary output is code/COMP-PAER/out/fsum100.txt, from the COMP-PAER Quantum ESPRESSO run (SG15, Γ; the 16-band version of the same sum is in code/COMP-PAER/scripts/formfactor.py):

```

q=0.10 A^-1 N_m=30 ratio=0.851
q=0.10 A^-1 N_m=50 ratio=0.855
q=0.10 A^-1 N_m=100 ratio=0.883

q=0.50 A^-1 N_m=30 ratio=0.847
q=0.50 A^-1 N_m=50 ratio=0.860
q=0.50 A^-1 N_m=100 ratio=0.891
```

I did not rerun it. No script in code/ writes fsum100.txt, and the run needs the QE HDF5 wavefunctions and pw.x, which are not on the path here. The file is the only primary record. The 100-band shortfall at 0.5 Å⁻¹ is 1 − 0.891 = 0.109. That agrees with "a shortfall of 0.11 at the same N" at ch30/E-14:100, where the test momentum is 0.507 Å⁻¹.
